## Parameter point (all scripts)

```
J=1, h=2, Nq=4, Nf=2, omega_A=3, g=1.8
t_ent=0.40, t_free=0.08, tau=0.25, alpha=1.0
alpha_f=1.5, g_c=0.1, t_link=0.8
```

JC is **off** during the link window. `[H_link, Σn] = 0` ⇒ `E_res = N E_M` under unitary link dynamics.

## TEBD production runs

Large-N TEBD (N≤20 for S; N≤50 for energy) lived in separate Kaggle notebooks. Place those JSON outputs under `data/` if available. These five scripts cover the **exact / analytic anchors** cited in the papers.
